# Recipe Finder

Nama: Muhammad Fawwaz Arryaan
Kelas: 11B
Rombel: Mr. Stabit

## Fitur yang berhasil dibuat

- Menampilkan daftar resep dari API
- Fitur pencarian resep berdasarkan nama
- Filter resep berdasarkan cuisine dan tingkat kesulitan
- Menampilkan detail resep dalam modal
- Menambahkan dan menghapus resep dari daftar favorit
- Menyimpan favorit di LocalStorage agar tetap tersimpan di browser
- Menampilkan jumlah resep favorit yang tersimpan

## Kendala yang ditemukan

- Saat awal, data dari API belum bisa langsung ditampilkan karena perlu dipahami format JSON terlebih dahulu.
- Beberapa fitur seperti pencarian dan filter harus dipahami dengan baik agar hasilnya tidak salah.
- Menangani tombol favorit dan detail resep membutuhkan logika yang tepat agar bisa bekerja pada setiap kartu resep.
- Kadang proses debugging perlu dilakukan untuk memastikan data yang ditampilkan sesuai dengan kondisi user.

## Bagian yang masih belum dipahami

- Cara kerja beberapa fungsi JavaScript yang lebih kompleks masih perlu dipelajari lebih lanjut.
- Masih perlu latihan untuk memahami alur DOM dan event listener dengan lebih mendalam.
- Beberapa logika pengolahan data di JavaScript masih terasa belum sepenuhnya dikuasai.

## Kesimpulan

Project Recipe Finder ini berhasil dibuat dengan fitur utama pencarian, filter, detail resep, dan favorit. Masih ada beberapa bagian yang perlu dipelajari lebih lanjut agar kemampuan JavaScript menjadi lebih optimal.
